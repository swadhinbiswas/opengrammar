    🚀 Getting Started

    Prerequisites

    Required:

    • Node.js 18+ or Bun
    • Git
    • Code editor (VS Code recommended)

    Nice to have:

    • Experience with TypeScript
    • Browser extension development knowledge
    • React familiarity

    Quick Setup

    1. Fork the repository
    

    Click "Fork" on GitHub
    


    2. Clone your fork
    

    git clone https://github.com/YOUR_USERNAME/opengrammar.git
    

    cd opengrammar
    


    3. Add upstream remote
    

    git remote add upstream https://github.com/swadhinbiswas/opengrammar.git
    


    4. Install dependencies
    

    cd opengrammar/opengrammar
    

    bun install
    


    5. Start development
    

    bun run dev

    📤 Submitting Pull Requests

    Before Submitting

    Checklist:

    • [ ] Code compiles without errors
    • [ ] Tests pass (if applicable)
    • [ ] Code is formatted
    • [ ] Documentation updated
    • [ ] Tested in browser
    • [ ] No console errors

    Creating PR

  • Push to Your Fork

    •    git push origin feature/your-feature-name

  • Open Pull Request

    • - Go to your fork on GitHub

    - Click "Pull requests"

    - Click "New pull request"

    - Select your branch

    - Compare to main branch

  • Fill Out Template

    •    ## Description
    

       Brief description of changes
    


       ## Type of Change
    

       - [ ] Bug fix
    

       - [ ] New feature
    

       - [ ] Documentation update
    

       - [ ] Performance improvement
    


       ## Testing
    

       Describe how you tested:
    

       - [ ] Manual testing in browser
    

       - [ ] Unit tests added/updated
    

       - [ ] Tested on Chrome/Brave/Edge
    


       ## Checklist
    

       - [ ] Code follows style guidelines
    

       - [ ] Self-review completed
    

       - [ ] No console errors
    

       - [ ] Documentation updated

  • Submit PR

    • - Click "Create pull request"

    - Wait for review

    - Respond to feedback

    PR Review Process

  • Automated Checks

    • - CI/CD runs tests

    - Type checking

    - Build verification

  • Maintainer Review

    • - Code quality check

    - Functionality verification

    - Security review

  • Feedback & Changes

    • - Respond to comments

    - Make requested changes

    - Push updates to branch

  • Merge

    • - PR approved

    - All checks pass

    - Merged to main

    📚 Adding Grammar Rules

    Where Rules Live

    Rules are in backend/src/analyzer-simple.ts

    Rule Structure

    {

      pattern: /\bteh\b/gi,
    

      suggestion: 'the',
    

      reason: 'Misspelled word. The correct spelling is "the".',
    

      type: 'spelling',
    

      severity: 'error'
    

    }

    Adding a New Rule

    Example: Add "alot" → "a lot"

    // In analyzer-simple.ts

    Testing Rules

    // Test the rule

    const text = "I have alot of work";
    

    const issues = checkCommonMisspellings(text);
    

    console.log(issues); // Should detect "alot"

    Rule Categories

    1. Spelling

    {

      pattern: /\brecieve\b/gi,
    

      suggestion: 'receive',
    

      reason: 'Misspelled word',
    

      type: 'spelling'
    

    }

    2. Grammar

    {

      pattern: /\bme and [a-z]+\b/gi,
    

      suggestion: 'I and [name]',
    

      reason: 'Use subject pronoun',
    

      type: 'grammar'
    

    }

    3. Style

    {

      pattern: /\bvery good\b/gi,
    

      suggestion: 'excellent',
    

      reason: 'Consider a stronger word',
    

      type: 'style'
    

    }

    4. Clarity

    {

      pattern: /.{35,}/g,  // Sentences > 35 chars
    

      suggestion: 'Shorten sentence',
    

      reason: 'Sentence may be hard to read',
    

      type: 'clarity'
    

    }

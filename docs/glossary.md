# Glossary

Common terms and definitions used in OpenGrammar.

## A

**Analysis Context**
Additional information about the writing environment that helps improve grammar checking accuracy.

**API Key**
A secret token used to authenticate with LLM providers (OpenAI, Groq, etc.).

**Autocomplete**
Feature that suggests the next word or phrase as you type.

## B

**Background Script**
Extension component that runs independently of web pages and manages extension lifecycle.

**Backend API**
Server-side service that processes text analysis requests.

## C

**Chrome Extension**
Browser add-on built for Google Chrome and compatible browsers.

**Cloudflare Workers**
Serverless platform used to deploy OpenGrammar backend.

**Content Script**
JavaScript that runs in the context of web pages to detect and highlight issues.

**Context Menu**
Right-click menu that provides quick access to rewrite features.

## D

**Dark Mode**
UI theme with dark background and light text for reduced eye strain.

**Debouncing**
Technique to delay analysis until user stops typing briefly.

## E

**Edge Function**
Serverless function that runs at the edge of the network for low latency.

**Extension Manifest**
JSON file (manifest.json) that defines extension configuration and permissions.

## G

**Grammar Rule**
Pattern-based check that detects specific grammar errors.

**Grammarly**
Popular commercial grammar checking service that OpenGrammar alternatives.

## H

**Highlight**
Visual underline or marker that indicates detected issues in text.

**Hono**
Lightweight web framework used for the backend API.

## I

**Ignored Issue**
A detected issue that the user has chosen to dismiss permanently.

**Issue**
A detected grammar, spelling, clarity, or style problem in text.

## L

**LLM (Large Language Model)**
AI model used for advanced grammar checking and text analysis.

**LLM Provider**
Service that provides access to LLMs (OpenAI, Groq, Together, etc.).

**Lucide React**
Icon library used in OpenGrammar UI.

## M

**Manifest V3**
Latest Chrome extension platform version with improved security and performance.

## O

**OpenGrammar**
This project - a privacy-first, open-source writing assistant.

**OpenRouter**
Unified API that provides access to multiple LLM providers.

## P

**Passive Voice**
Writing style where the subject receives the action (detected by OpenGrammar).

**Provider**
See LLM Provider.

## R

**Rate Limit**
Maximum number of API requests allowed in a time period.

**Rewrite**
Feature that transforms text to a different tone or style.

**Rule-Based Analysis**
Grammar checking using predefined patterns and rules (works offline).

## S

**Serverless**
Architecture where backend runs without managing servers.

**Service Worker**
Background script type used in Manifest V3 extensions.

**Sensitivity**
Setting that controls how strict the grammar checking is.

## T

**Tone**
Style of writing (formal, casual, professional, etc.) that can be applied via rewrite.

**TypeScript**
Typed superset of JavaScript used throughout OpenGrammar.

## V

**Vite**
Build tool and dev server used for the extension.

## W

**WASM (WebAssembly)**
Binary instruction format that can improve performance (planned feature).

**Web Extensions API**
Browser API for building extensions (chrome.*, browser.*).

Overview

OpenGrammar is a powerful, self-hostable browser extension that helps you write clearly and confidently everywhere on the web. It's built to feel like the premium writing assistants you know, but with a critical difference: you control your data, and it can run completely for free.

Why OpenGrammar?
Most popular grammar assistants require you to send every keystroke to their servers and charge a hefty monthly fee for advanced features. OpenGrammar changes that.
💰
Zero Cost Option
The core engine runs locally in your browser, checking for passive voice, repetition, and readability without needing a server.
🤖
Bring Your Own AI
Paste your own API key (OpenAI, Groq, OpenRouter). You pay only fractions of a cent for what you actually use.
🔒
Absolute Privacy
No database, no accounts. Your API key never leaves your browser. Data is processed and immediately forgotten.
🚀
Open Source
Deploy to Cloudflare Workers or Vercel Edge for free. You own the infrastructure completely.

Quick Start Guide

Get up and running with OpenGrammar in 5 minutes!

Prerequisites

  • Node.js (v18 or newer)
  • npm, pnpm, or yarn
  • Chrome browser (or Chromium-based)

Installation Steps

Clone the Repository

git clone https://github.com/swadhinbiswas/opengrammar.git
cd opengrammar

Install Dependencies

# Install all dependencies
bun install

# Or with npm
npm install

Set Up the Backend

cd opengrammar/backend
npm run dev

Runs on http://localhost:8787

Build the Extension

cd opengrammar/extension
npm run build

Load in Chrome

  1. Open chrome://extensions/
  2. Enable Developer Mode
  3. Click "Load unpacked"
  4. Select opengrammar/extension/dist

Configure & Go!

Click the OpenGrammar icon in your toolbar. Paste your API key to enable AI features, or start writing with free offline mode!

Browser Extension Setup

Note: Since this is an open-source developer project, it is not yet published on the Chrome Web Store. You will need to load it manually.

Manual Installation (Chrome)

Download/Clone

Download the latest release or clone this repository.

Open Extensions Page

In Chrome, go to chrome://extensions/

Enable Developer Mode

Toggle the switch in the top right corner.

Load Unpacked

Click "Load unpacked" and select the dist folder.

Configure Extension

  1. Click the OpenGrammar icon in your browser toolbar
  2. Paste your API key (optional for AI features)
  3. Choose your preferred AI provider and model
  4. You're ready to write!

Using OpenGrammar

How It Works

OpenGrammar automatically detects text inputs, textareas, and rich text editors on any webpage. It works seamlessly across:

  • Gmail & Google Docs
  • Notion & Evernote
  • Reddit & social media
  • WordPress & CMS platforms
  • And thousands of other sites!

Real-Time Checking

With 800ms debounce, OpenGrammar checks your text as you type without slowing you down. Issues are highlighted with color-coded underlines:

  • Red - Grammar/Spelling errors
  • Amber - Clarity improvements
  • Blue - Style suggestions

Interactive Tooltips

Click any underlined text to see:

  • The original text
  • Suggested correction
  • Reason for the suggestion
  • Apply / Ignore buttons
  • Confidence score
  • Add to dictionary option
Offline Mode: The rule-based engine works completely offline! No internet required for basic grammar checking. AI features require an API key and internet.

POST /analyze

Analyze text for grammar, spelling, and style issues.

Request

{
  "text": "me and him went to store",
  "provider": "groq",
  "model": "llama-3.1-70b-versatile",
  "apiKey": "gsk_xxx"
}

Response

{
  "issues": [
    {
      "type": "grammar",
      "original": "me and him",
      "suggestion": "he and I",
      "reason": "Subject pronoun error",
      "offset": 0,
      "length": 9,
      "confidence": 0.96,
      "priority": 95.0
    }
  ],
  "metadata": {
    "textLength": 24,
    "issuesCount": 1,
    "processingTimeMs": 245,
    "provider": "groq"
  }
}

POST /rewrite

Rewrite text in a different tone.

Request

{
  "text": "hey whats up",
  "tone": "formal",
  "provider": "groq",
  "model": "llama-3.1-70b-versatile"
}

Response

{
  "original": "hey whats up",
  "rewritten": "Greetings, how are you?",
  "tone": "formal"

Adding Grammar Rules

Edit opengrammar/backend/src/analyzer-simple.ts:

{
  pattern: /\bword\b/gi,
  suggestion: 'correction',
  reason: 'Explanation of the error.',
  type: 'spelling'
}
Rule Categories Needed: Common misspellings, confused words, redundant phrases, style & clarity rules, punctuation & spacing.

Code Style

  • TypeScript strict mode
  • Conventional commits (feat, fix, docs, refactor, test)
  • Descriptive branch names: feature/add-tone, fix/grammar-detection

Troubleshooting

Common Issues

Extension Not Loading

Solution:
  1. Make sure you built the extension: cd extension && npm run build
  2. Check that you're loading the dist folder
  3. Refresh the extensions page and try again

AI Features Not Working

Solution:
  1. Verify your API key is correctly entered
  2. Check that the backend is running
  3. Update backendUrl in extension settings
  4. Check browser console for errors

Highlighting Not Showing

Solution:
  1. Make sure the extension is enabled
  2. Check if the site is in disabled domains
  3. Some sites may not support content scripts

Backend Connection Failed

# Check if backend is running
curl http://localhost:8787/health

# Check CORS settings
# Make sure backend URL in extension matches

Getting Help

  • Check GitHub Issues for known problems
  • Join our Discussions for questions
  • Run in debug mode: set DEBUG=true in backend

Frequently Asked Questions

Is OpenGrammar really free?

Yes! The rule-based engine is completely free and works offline. AI features require your own API key, which costs fractions of a cent per use with providers like Groq.

Is my data safe?

Absolutely. We have no database, no user accounts, and your API key never leaves your browser. If you use AI features, text is processed by stateless edge functions and immediately forgotten.

Can I self-host the backend?

Yes! Deploy to Cloudflare Workers, Vercel, Railway, Render, or any Docker-compatible platform in minutes.

What AI providers are supported?

Groq, OpenAI, OpenRouter, Together AI, Ollama, and any OpenAI-compatible API.

Does it work on mobile?

Currently, OpenGrammar is a Chrome/Chromium browser extension. Mobile support is planned for future versions.

How do I add custom grammar rules?

Edit opengrammar/backend/src/analyzer-simple.ts and add your regex-based rules. No coding experience needed for simple rule suggestions!

Can I use my own LLM locally?

Yes! Use Ollama with our Docker setup for completely offline AI-powered grammar checking.

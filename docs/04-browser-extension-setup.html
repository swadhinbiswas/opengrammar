🔧 Installation

Google Chrome

Step 1: Build the Extension

Navigate to extension folder


cd opengrammar/opengrammar/extension



Install dependencies


bun install



Build for production


bun run build

This creates a dist/ folder with the built extension.

Step 2: Load in Chrome

  • Open Chrome
  • Navigate to chrome://extensions/
  • Enable Developer mode (toggle in top-right corner)
  • Click Load unpacked
  • Select the opengrammar/extension/dist folder
  • Click Select

    • ✅ Extension loaded! You'll see the OpenGrammar icon in your toolbar.

    Step 3: Pin to Toolbar (Optional)

  • Click the puzzle piece icon (Extensions) in toolbar
  • Find OpenGrammar in the list
  • Click the pin icon 📌

    • Mozilla Firefox

    ⚠️ Note: Firefox support is temporary. The extension must be reloaded each time you restart Firefox.

    Step 1: Build the Extension

    cd opengrammar/opengrammar/extension

    bun install
    

    bun run build

    Step 2: Load in Firefox

  • Open Firefox
  • Navigate to about:debugging#/runtime/this-firefox
  • Click Load Temporary Add-on
  • Navigate to opengrammar/extension/dist
  • Select manifest.json
  • Click Open

    • ✅ Extension loaded!

    ⚠️ Important: This extension will be unloaded when you close Firefox. You'll need to reload it each session.

    Opera

    Step 1: Enable Chrome Extensions

  • Open Opera
  • Go to Settings
  • Enable "Allow extensions from other stores"

    • Step 2: Install Chrome Extension Loader

  • Visit Opera Add-ons
  • Search for "Install Chrome Extensions"
  • Add to Opera

    • Step 3: Load OpenGrammar

  • Navigate to chrome://extensions/
  • Enable Developer mode
  • Load unpacked → opengrammar/extension/dist

    • Vivaldi

    Step 1: Load in Vivaldi

  • Open Vivaldi
  • Navigate to vivaldi://extensions/
  • Enable Developer mode
  • Click Load unpacked
  • Select opengrammar/extension/dist

    • ⚙️ Initial Configuration

    Step 1: Open Settings

  • Click the OpenGrammar icon in your toolbar
  • Click the Settings (gear) icon

    • Step 2: Configure Backend URL

  • Find Backend URL field
  • Enter your backend URL:

    • - Local: http://localhost:8787

    - Cloudflare: https://opengrammar.yourname.workers.dev

    - Vercel: https://opengrammar-backend.vercel.app

    - Railway: https://your-app.railway.app

    - Render: https://opengrammar-backend.onrender.com

    - Docker: http://localhost:8787

    Step 3: Configure AI Provider

  • Select Provider from dropdown:

    • - Groq (Recommended - Free tier)

    - OpenAI (Best quality)

    - OpenRouter (100+ models)

    - Together AI (Open-source)

    - Ollama (Local, offline)

    - Custom (Your own API)

  • Enter your API Key (if required)
  • Select Model from dropdown

    • Step 4: Test Connection

  • Look for the status indicator
  • 🟢 Green = Connected
  • 🔴 Red = Not connected

    • Step 5: Save Settings

    Click Save to apply changes.

    🔍 Verifying Installation

    Test 1: Check Extension Icon

  • Click the OpenGrammar icon
  • Popup should open
  • You should see settings and status

    • Test 2: Check Grammar

  • Open any text box (Gmail, Google Docs, etc.)
  • Type: me and him went to store
  • You should see a red underline under "me and him"

    • Test 3: Check Backend Connection

  • Click extension icon
  • Look for status indicator
  • Should be green with "Connected"

    • Test 4: Test Rewrite Feature

  • Select any text on a webpage
  • Right-click
  • Choose Rewrite with OpenGrammar
  • Rewrite popup should open

    🔄 Updating the Extension

    Manual Update

    Rebuild extension
    

    cd opengrammar/opengrammar/extension
    

    bun run build
    


    Reload in browser
    

    chrome://extensions/ → Click reload icon on OpenGrammar

    Automatic Updates

    Since this is a locally-loaded extension, it won't auto-update. You need to:

  • Rebuild manually
  • Reload in extensions page

    • 🆘 Troubleshooting

    Extension Not Showing

    Problem: Can't find OpenGrammar icon

    Solution:

  • Check chrome://extensions/ (or browser equivalent)
  • Make sure extension is enabled
  • Click the puzzle piece icon → Pin OpenGrammar

    • No Grammar Highlights

    Problem: Typing errors but no underlines appear

    Solution:

  • Check extension is enabled (icon badge visible)
  • Verify site is not in disabled domains
  • Check backend is running: curl http://localhost:8787/health
  • Reload the page
  • Check browser console (F12) for errors

    • Backend Not Connecting

    Problem: Red status indicator, "Not connected" error

    Solution:

  • Verify backend URL in settings
  • Test backend: curl your-backend-url/health
  • Check CORS configuration
  • Restart backend service
  • Check firewall settings

    • Extension Crashes

    Problem: Extension closes or stops working

    Solution:

  • Reload extension in extensions page
  • Clear browser cache
  • Check browser console for errors
  • Rebuild extension
  • Try in incognito mode (enable in extensions page)

    • Rewrite Not Working

    Problem: Right-click menu doesn't appear

    Solution:

  • Make sure text is selected
  • Check extension is enabled
  • Reload the page
  • Check browser permissions
  • Try keyboard shortcut: Ctrl+Shift+R

    • Settings Not Saving

    Problem: Settings reset after closing

    Solution:

  • Check browser storage permissions
  • Clear browser data for extension
  • Try in a fresh browser profile
  • Export settings before resetting

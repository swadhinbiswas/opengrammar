# Changelog

All notable changes to OpenGrammar will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Comprehensive JSDoc documentation for all TypeScript types
- EditorConfig for consistent code formatting across editors
- Prettier configuration for automated code formatting
- ESLint configurations for both extension and backend
- Enhanced error handling in backend API endpoints

### Changed
- Improved type safety with detailed interface documentation
- Better code consistency with standardized formatting rules

### Fixed
- Various documentation improvements

## [1.0.0] - 2024-03-21

### Added
- Initial release of OpenGrammar
- Rule-based grammar analyzer with offline support
- AI-powered grammar checking with multiple LLM providers
- Browser extension for Chrome/Chromium browsers
- Self-hosted backend API for privacy-first operation
- Support for OpenAI, Groq, Together, OpenRouter, and Ollama
- Tone rewriting feature with 8 different styles
- Writing statistics and readability scores
- Real-time grammar highlighting in text inputs
- Context menu integration for quick rewrites
- Custom dictionary support
- Ignored issues persistence

### Supported Providers
- OpenAI (GPT-4, GPT-3.5-turbo)
- Groq (Llama, Mixtral)
- Together AI (various open models)
- OpenRouter (unified API)
- Ollama (local models)

### Features
- Works everywhere: Gmail, Google Docs, Notion, Reddit, etc.
- Privacy-first: No data stored on servers
- Free to use with your own API keys
- Self-hostable backend
- Open source under Apache 2.0 license
